# Data-Analysis-Project
## Лабораторная работа: предобработка и визуализация данных о медицинских расходах

Блокнот `lab.ipynb` — первичный анализ датасета **Medical Cost Personal Datasets** (`insurance.csv`, Kaggle: `abdullahcetin/mirichoi0218insurance`).

## Данные

1338 записей, 7 признаков:

| Признак | Тип | Описание |
|---|---|---|
| `age` | числовой | возраст |
| `sex` | категориальный | пол |
| `bmi` | числовой | индекс массы тела |
| `children` | числовой | количество детей |
| `smoker` | категориальный | курит ли |
| `region` | категориальный | регион проживания |
| `charges` | числовой | медицинские расходы, $ |

## Что делается в блокноте

1. **Загрузка** датасета через `kagglehub`.
2. **Предобработка:**
   - проверка типов данных (при необходимости приведение к числовым);
   - поиск пропусков — их нет;
   - поиск и удаление дубликатов — найден и удалён 1, осталось 1337 строк.
3. **Визуализация:**
   - гистограммы `age`, `bmi`, `children`, `charges`;
   - столбчатые диаграммы по `sex`, `smoker`, `region`;
   - boxplot расходов по `smoker`, `sex`, `region`;
   - диаграммы рассеяния «возраст — расходы» и «ИМТ — расходы» с разбивкой по курению.

## Запуск

```bash
pip install kagglehub numpy pandas matplotlib seaborn jupyter
jupyter notebook lab.ipynb
```

Датасет скачивается автоматически при выполнении ячейки загрузки (нужен доступ в интернет).

## Стек

Python 3, pandas, NumPy, matplotlib, seaborn, kagglehub.
